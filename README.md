# Cybersecurity Study Room

A browser-based exam study website for Units 1 and 2.

- 23 chapters and 230 sections
- 37 worked paper and class examples
- Topic search, bookmarks, and browser-local progress
- Revision questions and a 50-mark practice paper
- Adjustable reading text, dark theme, and mobile layout
- Official class notes incorporated; repeated material consolidated
- PKI infrastructure excluded; extensions explicitly marked

Open `index.html` in a browser, or enable GitHub Pages from the `main` branch at the repository root. The site needs no build step or external dependencies.

The PDF is included for offline study. Progress and bookmarks are stored in the browser rather than synchronized between devices.

Symmetric slide details: interactive AES inverse operations, P-boxes and S-boxes, mode error propagation, RC4 state tracing, and historical cryptanalysis. All 59 pages of Intro_Symm-Crypto.pdf reviewed; repeated explanations consolidated.
