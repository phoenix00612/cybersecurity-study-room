Finite-field worked solution · pages 5–6

With A = 1101, B = 1011 and P = 10011, the unreduced product is 1111111. Polynomial reduction is:

1111111 XOR 1001100 = 0110011
0110011 XOR 0100110 = 0010101
0010101 XOR 0010011 = 0000110

Correct remainder: 0110 = x² + x. The source's 0100 drops a surviving x term. The correction is used in this bank.

Extra RSA question · page 7

For n = 143 = 11×13, φ(n) = 120 and λ(n) = 60. The stated d = 27 has gcd 3 with both, so it cannot be a standard valid RSA private exponent for these primes.

The power 9²⁷ mod 143 = 92 is still computable. The bank distinguishes that power exercise from a valid key. New RSA variants use checked exponents.

FERMAT / EULER

Inspect the modulus and coprimality

  1. Factor the modulus if it is composite.
  2. Check gcd(a,n)=1 where required.
  3. Apply Fermat to prime factors, or Euler with the right totient.
  4. Make the exponent compatible with each factor.
  5. Combine only with justified coprime-factor reasoning.

Trap: a result modulo p and q does not automatically establish the corresponding prime-power result modulo p².

ECC / ECDH

Choose the group operation first

  1. Check the curve and input points.
  2. Handle O, inverse points and y=0 before division.
  3. Add with (y₂−y₁)/(x₂−x₁); double with (3x²+a)/(2y).
  4. Replace division by an inverse modulo p.
  5. Reduce x and y, then check membership or shared-point agreement.

Trap: private scalars are not coordinate multipliers. αP is repeated group addition.

RSA

Build the square residues again

  1. Check n, key conditions and the representative range.
  2. Write d in binary / powers of two.
  3. Square and reduce modulo n at every step.
  4. Multiply the selected residues and reduce.
  5. If e is available, re-encrypt to check.

Trap: Euler reduction requires a coprime base. Repeated squaring works for non-coprime bases too.

GF(2⁴)

Carryless product, then polynomial reduction

  1. Map bit positions to polynomial powers.
  2. Multiply by shifts and XOR, with no integer carries.
  3. Cancel repeated terms in pairs.
  4. Use the stated irreducible polynomial, not one remembered from a different example.
  5. Write the degree-below-4 remainder as exactly four bits.

Trap: mod 16 is integer arithmetic, not reduction in this polynomial field.

Three theorem traps to test yourself on

Missing coprimality: a=5 cannot make 65 divide a⁴⁸−1, because that expression is −1 mod 5.

Wrong exponent: the claim that 77 divides a¹⁵−1 for every coprime a is false. a=2 gives 2¹⁵ mod 77=43, not 1.

Prime power: a⁴≡1 mod 5 does not imply a⁴≡1 mod 25. a=2 gives 2⁴ mod 25=16. Euler instead gives a²⁰≡1 mod 25 for coprime a.
